Criar e hospedar um site estático usando **HTML5**, **Bootstrap 5** (via CDN) e **GitHub Pages** é o caminho mais rápido e simples para colocar um projeto no ar gratuitamente.

---

## 1. Estrutura do Código (`index.html`)

Crie um arquivo chamado `index.html` no diretório raiz do seu projeto com o código base abaixo:

```html
<!DOCTYPE html>
<html lang="pt-BR">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Meu Site Estático</title>

  <!-- Bootstrap 5 CSS CDN -->
  <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body class="bg-light">

  <nav class="navbar navbar-expand-lg navbar-dark bg-dark">
    <div class="container">
      <a class="navbar-brand" href="#">Meu Projeto</a>
    </div>
  </nav>

  <main class="container my-5">
    <div class="p-5 mb-4 bg-white rounded-3 shadow-sm">
      <h1 class="display-5 fw-bold">Olá, GitHub Pages!</h1>
      <p class="col-md-8 fs-4">Este é um site estático responsivo construído com HTML5 e Bootstrap 5.</p>
      <a href="https://getbootstrap.com" target="_blank" class="btn btn-primary btn-lg">Documentação Bootstrap</a>
    </div>
  </main>

  <!-- Bootstrap 5 JS Bundle CDN -->
  <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>

```

---

## 2. Publicação no GitHub Pages

Siga a sequência abaixo no seu terminal para enviar o projeto e ativar a hospedagem:

1. **Inicializar o repositório e enviar o código:** Certifique-se de ter o Git instalado no seu sistema.
Navegue até a pasta do projeto no terminal e execute:

```bash
git init
git add index.html
git commit -m "feat: initial commit with bootstrap template"
git branch -M main
git remote add origin https://github.com/SEU_USUARIO/NOME_DO_REPOSITORIO.git
git push -u origin main

```


2. **Configurar a hospedagem no GitHub Pages:** Acesse o repositório pelo navegador.
1. Acesse o repositório no **GitHub**.
2. Vá em **Settings** > **Pages** (no menu lateral esquerdo em *Code and automation*).
3. Em **Build and deployment** > **Source**, selecione **Deploy from a branch**.
4. Em **Branch**, selecione `main` e a pasta `/ (root)`.
5. Clique em **Save**.


3. **Acessar o site publicado:**
Aguarde cerca de 1 a 2 minutos até que a compilação termine. Seu site estará disponível publicamente no endereço:

`https://SEU_USUARIO.github.io/NOME_DO_REPOSITORIO/`
