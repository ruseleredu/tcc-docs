🌐 Site estático com HTML + Bootstrap + GitHub Pages

Este guia apresenta a maneira mais simples de criar, editar, visualizar localmente e publicar um site estático utilizando:

  • HTML5
  • Bootstrap 5
  • CSS
  • JavaScript
  • Visual Studio Code
  • Live Server
  • Git
  • GitHub Pages

A proposta é evitar frameworks e geradores de sites estáticos. O site é composto diretamente por arquivos HTML e recursos estáticos.

1. Arquitetura

A arquitetura utilizada é extremamente simples:

                    ┌─────────────────┐
                    │    VS Code      │
                    │                 │
                    │ HTML            │
                    │ CSS             │
                    │ JavaScript      │
                    └────────┬────────┘
                             │
                             │ edição
                             ▼
                    ┌─────────────────┐
                    │   Live Server   │
                    └────────┬────────┘
                             │
                             │ localhost
                             ▼
                    ┌─────────────────┐
                    │    Browser      │
                    └─────────────────┘


                    PUBLICAÇÃO
                         │
                         ▼
                    ┌─────────────┐
                    │    Git      │
                    └──────┬──────┘
                           │
                           ▼
                    ┌─────────────┐
                    │   GitHub    │
                    └──────┬──────┘
                           │
                           ▼
                    ┌─────────────┐
                    │ GitHub Pages│
                    └──────┬──────┘
                           │
                           ▼
                    🌐 Site publicado

Não existe:

  • Jekyll
  • Hugo
  • Eleventy
  • Astro
  • Docusaurus
  • Node.js
  • npm
  • banco de dados
  • servidor backend

O GitHub Pages simplesmente entrega os arquivos estáticos ao navegador.

2. Pré-requisitos

Instale:

Visual Studio Code​

Baixe e instale o VS Code.

Git​

Instale o Git para versionar o projeto e enviá-lo para o GitHub.

Navegador​

Qualquer navegador moderno:

  • Firefox
  • Chrome
  • Edge
  • Brave

3. Criar o projeto

Crie uma pasta para o site.

Por exemplo:

meu-site/

No Windows:

mkdir meu-site
cd meu-site

Depois abra a pasta no VS Code:

code .

Ou utilize:

VS Code
→ File
→ Open Folder
→ meu-site

4. Estrutura de diretórios

Comece com a seguinte estrutura:

meu-site/
│
├── index.html
│
├── about.html
│
├── css/
│   └── style.css
│
├── js/

Posteriormente podemos acrescentar:

meu-site/
│
├── index.html
├── about.html
├── contact.html
│
├── css/

│
├── js/

│
├── img/
│   ├── logo.png
│   └── banner.jpg
│
└── docs/

5. Criar a página HTML

Crie:

index.html

Utilize a estrutura HTML5 básica:

<!doctype html>

<html lang="pt-BR">

<head>

    <meta charset="utf-8">

    <meta
        name="viewport"
        content="width=device-width, initial-scale=1">

    <title>Meu Site</title>

</head>

<body>

    <h1>Meu Site</h1>

    <p>
        Meu primeiro site estático.
    </p>

</body>

</html>

Salve o arquivo.

6. Adicionar Bootstrap

A maneira mais simples de utilizar Bootstrap é através do CDN.

No <head>:

<link
    href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/css/bootstrap.min.css"
    rel="stylesheet">

Antes do fechamento de </body>:

<script
    src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/js/bootstrap.bundle.min.js">
</script>

A página completa fica:

<!doctype html>

<html lang="pt-BR">

<head>

    <meta charset="utf-8">

    <meta
        name="viewport"
        content="width=device-width, initial-scale=1">

    <title>Meu Site</title>

    <link
        href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/css/bootstrap.min.css"
        rel="stylesheet">

</head>

<body>

    <main class="container py-5">

        <h1 class="display-4">
            Meu Site
        </h1>

        <p class="lead">
            Site estático utilizando HTML e Bootstrap.
        </p>

        <button class="btn btn-primary">
            Começar
        </button>

    </main>

    <script
        src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/js/bootstrap.bundle.min.js">
    </script>

</body>

</html>

7. Criar CSS personalizado

Bootstrap resolve grande parte do layout, mas você pode criar seu próprio CSS.

Crie:

css/style.css

Exemplo:

body {
    background-color: #f8f9fa;
}

.hero {
    padding: 6rem 0;
}

.footer {
    margin-top: 4rem;
    padding: 2rem 0;
}

Depois carregue o CSS:

<link
    rel="stylesheet"
    href="css/style.css">

O <head> ficará:

<head>

    <meta charset="utf-8">

    <meta
        name="viewport"
        content="width=device-width, initial-scale=1">

    <title>Meu Site</title>

    <link
        href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/css/bootstrap.min.css"
        rel="stylesheet">

    <link
        rel="stylesheet"
        href="css/style.css">

</head>

8. Adicionar JavaScript

Crie:

js/app.js

Exemplo:

console.log("Site carregado!");

No HTML:

<script src="js/app.js"></script>

Normalmente o script deve ser colocado antes de </body>:

<body>

    ...

    <script
        src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/js/bootstrap.bundle.min.js">
    </script>

    <script src="js/app.js"></script>

</body>

9. Visualizar no VS Code

9.1 Instalar Live Server​

No VS Code:

Extensions
→ procurar "Live Server"
→ Install

Depois abra:

index.html

Clique com o botão direito:

Open with Live Server

O navegador abrirá algo parecido com:

http://127.0.0.1:5500/

ou:

http://localhost:5500/

9.2 Live Reload​

Agora altere:

<h1 class="display-4">
    Meu Site
</h1>

para:

<h1 class="display-4">
    Meu Site com Bootstrap
</h1>

Salve:

Ctrl + S

O navegador será atualizado automaticamente.

O ciclo de desenvolvimento é:

Editar
   ↓
Ctrl + S
   ↓
Live Server
   ↓
Browser atualizado

Não é necessário executar comandos de build.

Crie:

about.html

Exemplo:

<!doctype html>

<html lang="pt-BR">

<head>

    <meta charset="utf-8">

    <meta
        name="viewport"
        content="width=device-width, initial-scale=1">

    <title>Sobre</title>

    <link

        rel="stylesheet"

    <main class="container py-5">

        <h1>Sobre</h1>

        <p>

        </p>

        <a
            href="index.html"
            class="btn btn-primary">

            Voltar

        </a>

    </main>

</body>

</html>

Agora:

index.html
    │
    └── about.html

11. Criar uma barra de navegação

O Bootstrap fornece um componente Navbar.

Exemplo:

<nav class="navbar navbar-expand-lg bg-dark navbar-dark">

    <div class="container">

        <a
            class="navbar-brand"
            href="index.html">

            Meu Site

        </a>

        <button
            class="navbar-toggler"
            type="button"
            data-bs-toggle="collapse"
            data-bs-target="#navbarNav">

            <span class="navbar-toggler-icon"></span>

        </button>

        <div
            class="collapse navbar-collapse"
            id="navbarNav">

            <ul class="navbar-nav ms-auto">

                <li class="nav-item">

                    <a
                        class="nav-link"
                        href="index.html">

                        Início

                    </a>

                </li>

                <li class="nav-item">

                    <a
                        class="nav-link"
                        href="about.html">

                        Sobre

                    </a>

                </li>

            </ul>

        </div>

    </div>

</nav>

O JavaScript do Bootstrap precisa estar carregado para o menu responsivo funcionar.

index.html

    ↓
index.html

Responsividade​

No navegador:

F12
→ Toggle Device Toolbar

Teste:

Mobile

F12

Links​

Teste todos os links.

Imagens​

Verifique se todas as imagens aparecem corretamente.

14. Criar o repositório no GitHub

Crie um novo repositório no GitHub.

Por exemplo:

meu-site

Não é necessário adicionar:

  • README
  • .gitignore
  • licença

se você já possui o projeto local.

15. Inicializar Git

No terminal do VS Code:

git init

Adicione os arquivos:

git add .

Crie o primeiro commit:

git commit -m "Initial site"

Defina a branch principal:

git branch -M main

Adicione o repositório remoto:

git remote add origin https://github.com/SEU-USUARIO/meu-site.git

Envie:

git push -u origin main

Substitua:

SEU-USUARIO

pelo seu usuário do GitHub.

16. Publicar com GitHub Pages

No GitHub:

Repository
    ↓
Settings
    ↓
Pages

Em:

Build and deployment

selecione:

Source:
Deploy from a branch

Branch:

main

Folder:

/ (root)

Clique:

Save

O GitHub Pages publicará o conteúdo do repositório.

A URL normalmente será:

https://SEU-USUARIO.github.io/meu-site/

17. Atualizar o site

Depois de fazer alterações:

git add .
git commit -m "Update site"
git push

O GitHub Pages atualizará o site.

O fluxo completo passa a ser:

18. Domínio personalizado

É possível utilizar um domínio próprio.

Por exemplo:

www.exemplo.com.br

em vez de:

usuario.github.io/meu-site/

No GitHub Pages você configura o domínio personalizado e depois cria os registros DNS correspondentes no provedor do domínio.

Simplicidade​

Não existe processo de build:

Desenvolvimento rápido​

O ciclo é:

Editar

Salvar
↓

Bootstrap​

Você pode utilizar praticamente todos os componentes do Bootstrap:

  • Navbar
  • Cards
  • Buttons
  • Alerts

  • Carousel
  • Accordion

  • Grid

Controle total​

Você controla diretamente:

HTML
CSS
JavaScript
Imagens

Portabilidade​

O site não depende de um framework.

Um arquivo:

index.html

pode ser aberto diretamente em praticamente qualquer navegador.

20. Limitações

A principal desvantagem aparece quando o número de páginas cresce.

Imagine:

100 páginas

e todas possuem:

<nav>
    ...
</nav>

Se você alterar o menu, precisará alterar várias páginas.

Também não existe automaticamente:

layouts
templates
includes
collections
Markdown

Nesse ponto, um gerador como Jekyll ou Eleventy começa a ser interessante.

21. Quando usar esta abordagem?

Use HTML + Bootstrap quando:

  • o site possui poucas páginas;
  • você quer máxima simplicidade;
  • o conteúdo é predominantemente HTML;
  • não precisa de blog complexo;
  • não precisa de templates;
  • quer editar tudo diretamente no VS Code;
  • quer publicar rapidamente no GitHub Pages;
  • quer evitar Node.js;
  • quer evitar Ruby;
  • quer evitar frameworks.

É especialmente adequado para:

Landing pages
Portfólios
Sites pessoais
Projetos acadêmicos
Pequenos sites institucionais
Protótipos
Páginas de projetos

22. Quando migrar para um gerador?

Se o projeto começar a ficar assim:

site/
├── 100+ páginas
├── documentação
├── blog
├── categorias
├── navegação complexa
├── templates
└── componentes reutilizáveis

considere migrar para:

Jekyll
Eleventy
Hugo
Astro
Docusaurus

A migração pode ser gradual.

Uma estratégia interessante é começar:

HTML + Bootstrap

e posteriormente evoluir para:

HTML + Bootstrap
        +
Jekyll/Eleventy

sem precisar abandonar o HTML existente.
